# Архитектура FarGitHub

## v0.2.0

FarGitHub — нативный DLL-плагин для Far Manager. Взаимодействие с GitHub выполняется напрямую через REST API по HTTPS с использованием WinHTTP. Внешний `git.exe` для работы с файлами не требуется.

### Основные компоненты

- `Plugin.cpp` — экспортируемый интерфейс Far Manager, меню и настройки.
- `Panel.cpp` — виртуальная панель Far Manager, навигация по репозиториям и содержимому.
- `GitHubClient.cpp` — HTTP-клиент и операции GitHub Contents API.
- `Settings.cpp` — хранение токена в настройках Far Manager с шифрованием Windows DPAPI.

### Конфигурация

Токен вводится через `F11 -> GitHub -> Settings`. После ввода плагин выполняет запрос `GET /user`. При успешной проверке токен сохраняется в Plugin Settings Far Manager в зашифрованном виде.

Переменные окружения `FAR_GITHUB_TOKEN` и `FAR_GITHUB_REPOSITORY` больше не используются.

### Работа с панелью

После открытия панели плагин получает список репозиториев текущего пользователя через `GET /user/repos`.

Внутри выбранного репозитория используется GitHub Contents API:

- получение каталога;
- чтение файла;
- загрузка изменённого файла после редактирования;
- создание каталога через `.gitkeep`;
- копирование локального файла на GitHub.

### Безопасность

Токен не записывается в исходный код, переменные окружения, логи или обычный текстовый файл. Для защиты используется Windows Data Protection API (`CryptProtectData` / `CryptUnprotectData`).

### Ограничения v0.2.0

- выбранная ветка пока не отображается отдельно;
- операции удаления и переименования файлов ещё не реализованы;
- создание нового файла из панели будет расширено в следующей версии;
- коммиты выполняются GitHub Contents API с одним commit message на операцию;
- история, pull request и полноценная Git-модель запланированы на следующие версии.
