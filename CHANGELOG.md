# Changelog

## 0.3.0

- Добавлен поиск репозиториев по имени и полному имени.
- Добавлено избранное для репозиториев.
- Избранные репозитории сохраняются в настройках Far Manager.
- Избранные репозитории отображаются в начале списка.
- Добавлены горячие клавиши `Ctrl+F` для поиска и `Ctrl+B` для избранного.
- Версия плагина переведена на 0.3.0.

## 0.2.0

- Добавлено окно настройки GitHub токена через Far Manager.
- Добавлено шифрование токена Windows DPAPI.
- Добавлена проверка токена через `GET /user`.
- Добавлено автоматическое получение списка репозиториев через `GET /user/repos`.
- Убраны переменные окружения `FAR_GITHUB_TOKEN` и `FAR_GITHUB_REPOSITORY`.
- Улучшен разбор JSON-ответов GitHub.
- Добавлено URL-кодирование путей файлов.
- Обновлена архитектура панели для режима списка репозиториев.
- Проект переведён на версию 0.2.0.

## 0.1.0

- Базовая DLL Far Manager.
- Виртуальная GitHub-панель.
- Навигация по содержимому одного репозитория.
- Чтение и запись файлов через GitHub Contents API.
- Создание каталогов через `.gitkeep`.
