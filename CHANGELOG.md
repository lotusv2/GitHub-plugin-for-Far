# Changelog

## 0.5.0

- Добавлены Far callbacks `GetFilesW` и `DeleteFilesW`.
- **F5** поддерживает копирование файлов из GitHub на локальную панель.
- **F5** поддерживает загрузку локальных файлов в выбранную ветку GitHub.
- **F8** удаляет файлы и каталоги из выбранной ветки с подтверждением.
- Добавлена рекурсивная обработка каталогов при копировании и удалении.
- Исправлена обработка существующих файлов при загрузке: ошибки, отличные от `404`, больше не игнорируются.
- В GitHub client добавлены операции удаления и переименования файлов.
- Обновлена версия CMake и ресурсов до 0.5.0.

## 0.4.0

- Добавлена загрузка списка веток репозитория через GitHub Branches API.
- Добавлено переключение между ветками через меню Far Manager.
- Для переключения ветки используется `Ctrl+Shift+B`.
- Текущая ветка отображается в заголовке панели репозитория.
- Чтение, редактирование, загрузка файлов и создание каталогов выполняются в выбранной ветке.
- Для списка веток учитываются защищённые ветки.
- Добавлена постраничная загрузка веток.
- Версия плагина переведена на 0.4.0.

## 0.3.0

- Добавлен поиск репозиториев по имени и полному имени.
- Добавлено избранное для репозиториев.
- Избранные репозитории сохраняются в настройках Far Manager.
- Избранные репозитории отображаются в начале списка.
- Добавлены горячие клавиши `Ctrl+F` для поиска и `Ctrl+B` для избранного.
- Версия плагина переведена на 0.3.0.

## 0.2.0

- Добавлено окно настройки GitHub токена через Far Manager.
- Добавлено шифрование токена Windows DPAPI.
- Добавлена проверка токена через `GET /user`.
- Добавлено автоматическое получение списка репозиториев через `GET /user/repos`.
- Убраны переменные окружения `FAR_GITHUB_TOKEN` и `FAR_GITHUB_REPOSITORY`.
- Улучшен разбор JSON-ответов GitHub.
- Добавлено URL-кодирование путей файлов.
- Обновлена архитектура панели для режима списка репозиториев.
- Проект переведён на версию 0.2.0.

## 0.1.0

- Базовая DLL Far Manager.
- Виртуальная GitHub-панель.
- Навигация по содержимому одного репозитория.
- Чтение и запись файлов через GitHub Contents API.
- Создание каталогов через `.gitkeep`.
